## 二、Milvus 向量数据库

### 连接

```python
from pymilvus import MilvusClient, DataType, AnnSearchRequest, RRFRanker

client = MilvusClient(uri="http://127.0.0.1:19530")     # uri 必须带 http://
print(client.list_collections())
```

### 建集合 + 建索引

> bge-m3 稠密向量固定 **1024** 维

```python
schema = MilvusClient.create_schema(auto_id=False, enable_dynamic_field=True)
schema.add_field("id", DataType.INT64, is_primary=True)
schema.add_field("vector", DataType.FLOAT_VECTOR, dim=1024)        # 稠密
schema.add_field("sparse_vector", DataType.SPARSE_FLOAT_VECTOR)    # 稀疏（不用写 dim）
schema.add_field("text", DataType.VARCHAR, max_length=4096)

index_params = MilvusClient.prepare_index_params()
index_params.add_index(field_name="vector", index_type="HNSW", metric_type="COSINE")
index_params.add_index(field_name="sparse_vector",
                       index_type="SPARSE_INVERTED_INDEX", metric_type="IP")

client.create_collection("demo_collection", schema=schema, index_params=index_params)
```

### 给已有集合补索引

> Attu 显示「向量索引不存在」时用这个

```python
index_params = MilvusClient.prepare_index_params()
index_params.add_index(field_name="vector", index_type="HNSW", metric_type="COSINE")
index_params.add_index(field_name="sparse_vector",
                       index_type="SPARSE_INVERTED_INDEX", metric_type="IP")
client.create_index("demo_collection", index_params)
```

### 写入 / 加载 / 删除

```python
client.upsert(collection_name="demo_collection", data=data_list)  # upsert 不重复
client.flush("demo_collection")            # 落盘
client.load_collection("demo_collection")  # 加载（不加载查不到数据！）

client.delete(collection_name="demo_collection", filter="id >= 0")  # 清数据
client.drop_collection("demo_collection")                            # 删集合
```

### 查看信息

```python
print(client.get_collection_stats("demo_collection"))   # 行数
print(client.describe_collection("demo_collection"))    # 结构（查 dim 用）
```

### 完整链路

```
① create_schema      设计结构
② create_collection  建集合（带 index_params）  ← 索引
③ upsert             写数据
④ flush              落盘
⑤ load_collection    加载        ← 缺这步查不到数据
⑥ search             检索
```

## 三、向量化（bge-m3）

### 加载模型

```python
from FlagEmbedding import BGEM3FlagModel

# 慢，只加载一次（放全局，不要放函数里）
embed_model = BGEM3FlagModel(r"D:\LANGCHANINDEMO\assets\models\bge-m3", use_fp16=False)
```

### 生成向量

> ⚠️ 返回的是**字典**，要取里面的值

```python
result = embed_model.encode(["国家所有权"], return_dense=True, return_sparse=True)

dense  = result["dense_vecs"][0]         # 稠密，1024 维
sparse = result["lexical_weights"][0]    # 稀疏，{词id: 权重} 字典
```

| 取什么 | 写法 |
|---|---|
| 稠密向量 | `result["dense_vecs"][0]` |
| 稀疏向量 | `result["lexical_weights"][0]` |

## 四、检索（三种）

### ① 稠密检索

```python
res = client.search(
    collection_name="demo_collection",
    data=[dense.tolist()],
    anns_field="vector",
    limit=5,
    search_params={"metric_type": "COSINE"},
    output_fields=["text"],
)
for hit in res[0]:
    print(hit["id"], hit["distance"], hit["entity"]["text"][:100])
```

### ② 稀疏检索

> 度量**只能用 IP**

```python
res = client.search(
    collection_name="demo_collection",
    data=[sparse],
    anns_field="sparse_vector",
    limit=5,
    search_params={"metric_type": "IP"},
    output_fields=["text"],
)
```

### ③ 混合检索 + RRF（推荐）

```python
req1 = AnnSearchRequest(data=[dense.tolist()], anns_field="vector",
                        param={"metric_type": "COSINE"}, limit=50)   # param 不是 params
req2 = AnnSearchRequest(data=[sparse], anns_field="sparse_vector",
                        param={"metric_type": "IP"}, limit=50)       # 稀疏固定 IP

res = client.hybrid_search(
    collection_name="demo_collection",
    reqs=[req1, req2],
    ranker=RRFRanker(k=60),      # 只有 k 一个参数
    limit=5,
    output_fields=["text"],
)
```

### 参数速查

| | 字段 | 度量 |
|---|---|---|
| 稠密 | `vector` | `COSINE` / `L2` |
| 稀疏 | `sparse_vector` | `IP` |

## 五、Function Calling（原生 SDK）

### 四步闭环

```python
from openai import OpenAI

client = OpenAI(
    api_key=os.getenv("OPENAI_API_KEY"),
    base_url=os.getenv("OPENAI_BASE_URL"),     # 新版只有 base_url，没有 api_base
)

# ① 带 tools 问一次 → 模型说要调什么
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=messages,
    tools=tools,                    # tools 是列表！
)
messages.append(resp.choices[0].message)

# ② 取参数（JSON 字符串 → 字典）
import json
tool_call = resp.choices[0].message.tool_calls[0]
args    = json.loads(tool_call.function.arguments)
call_id = tool_call.id

# ③ 执行函数，结果塞回去（字段名必须是 content）
result = my_function(**args)
messages.append({
    "role": "tool",
    "tool_call_id": call_id,
    "name": "my_function",
    "content": result,             # ← 放结果，不是放参数
})

# ④ 再问一次（打印 response 不是 resp！）
response = client.chat.completions.create(model="deepseek-chat", messages=messages)
print(response.choices[0].message.content)
```

### 响应链怎么读

```python
resp.choices[0].message.tool_calls
#   │       │       │        └─ 要调的工具（列表）
#   │       │       └─ 模型说的这条消息
#   │       └─ 取第一个候选（默认只要一个）
#   └─ 候选回复列表
```

## 六、LangChain 工具

### `@tool` + `bind_tools`（手动两步）

```python
from langchain.tools import tool
from langchain_openai import ChatOpenAI
from langchain_core.messages import HumanMessage, ToolMessage

@tool(description="获取城市在特定日期的天气")     # 描述给模型看，很重要
def get_weather(city: str, date: str) -> str:
    """获取城市在特定日期的天气"""
    return f"城市{city}在{date}的天气是晴朗的"

llm = ChatOpenAI(model="deepseek-chat",
                 api_key=os.getenv("OPENAI_API_KEY"),
                 base_url=os.getenv("OPENAI_BASE_URL"))
llm_with_tools = llm.bind_tools([get_weather])

# 第一次（invoke 要传列表，单个消息对象会报错）
human_message = HumanMessage(content="北京天气怎么样")
res = llm_with_tools.invoke([human_message])
ai_message = res

# 执行工具（args 已是字典，不用 json.loads）
tool_res = get_weather.invoke(res.tool_calls[0]["args"])
tool_message = ToolMessage(tool_call_id=res.tool_calls[0]["id"], content=tool_res)

# 第二次
final = llm_with_tools.invoke([human_message, ai_message, tool_message])
print(final.content)
```

### `@tool` 自动做了什么

| Python 里写的 | 自动变成 |
|---|---|
| 函数名 | `"name"` |
| 类型注解 `city: str` | `"type": "string"` |
| `description=` / docstring | `"description"` |
| 无默认值的参数 | 进 `required` |

## 七、create_agent（自动循环）

```python
from langchain.agents import create_agent

agent = create_agent(model=llm, tools=[get_weather])

# 一次性结果
res = agent.invoke({"messages": [{"role": "user", "content": "北京天气怎么样"}]})
print(res["messages"][-1].content)

# 流式（打字机效果）
for token, metadata in agent.stream(
    {"messages": [{"role": "user", "content": "北京天气怎么样"}]},
    stream_mode="messages",
):
    if token.content:
        print(token.content, end="", flush=True)
```

⚠️ `stream()` 不加 `stream_mode` 返回的是**字典**，`chunk[0]` 会报 `KeyError: 0`

### 三种写法对比

| | 原生 SDK | LangChain | create_agent |
|---|---|---|---|
| 写 Schema | 手写 JSON | `@tool` 自动生成 | `@tool` 自动生成 |
| 解析参数 | `json.loads` | `["args"]` 已字典 | 全自动 |
| 第二次请求 | 手动 | 手动 | **自动循环** |

## 八、MCP

### MCP Server

```python
from mcp.server import FastMCP

mcp = FastMCP()

@mcp.tool()                      # 自动从类型注解生成 JSON Schema
def search_law(keyword: str) -> str:
    """根据用户的问题检索民法典相关条文"""       # docstring → description
    return "法条内容"

if __name__ == "__main__":
    mcp.run(transport="stdio")                                            # 本地
    # mcp.run(transport="streamable-http", host="127.0.0.1", port=8000)   # 远程
```

⚠️ stdio 模式里**千万别 `print()`**，会污染通信流（要用 `file=sys.stderr`）

### MCP 客户端：stdio

> 返回 **2 个**值

```python
from mcp.client.stdio import stdio_client
from mcp import ClientSession, StdioServerParameters

server_params = StdioServerParameters(
    command=r"d:\LANGCHANINDEMO\.venv\Scripts\python.exe",              # ← 逗号别漏
    args=[r"D:\LANGCHANINDEMO\september\Day04\mcp_stdio_server.py"],    # 绝对路径最稳
)

async with stdio_client(server_params) as (read_stream, write_stream):
    async with ClientSession(read_stream, write_stream) as session:
        await session.initialize()

        tools_list = await session.list_tools()          # 括号！
        print([t.name for t in tools_list.tools])

        result = await session.call_tool("search_law", {"keyword": "国家所有权"})
        print(result.content)
```

### MCP 客户端：streamable-http

> 返回 **3 个**值，且要先手动启动 server

```python
from mcp.client.streamable_http import streamable_http_client

async with streamable_http_client(url="http://127.0.0.1:8000/mcp") as (read_stream, write_stream, _):
    async with ClientSession(read_stream, write_stream) as session:
        await session.initialize()
        result = await session.call_tool(name="search_law", arguments={"keyword": "国家所有权"})
        print(result.content)
```

### 两种模式对比

| | stdio | streamable-http |
|---|---|---|
| 谁启动 server | 客户端启动子进程 | **手动启动**，保持运行 |
| 返回值个数 | **2 个** `(read, write)` | **3 个** `(read, write, _)` |
| 用途 | 本地工具 | 远程服务、多客户端 |

### `call_tool` 固定写法

```python
await session.call_tool("工具名字符串", {"参数名": "值"})
```

⚠️ 客户端和 server 是**两个独立进程**，只能通过**字符串名字**调用

## 九、调试技巧

### 摸清一个陌生对象

```python
print(type(obj))                       # 先看类型
print(dir(obj))                        # 有哪些属性/方法
print(obj.model_dump_json(indent=2))   # pydantic 对象转 JSON（最有用）
help(obj.method)                       # 方法用法
```

### 属性 vs 方法

```python
print(obj.name)        # 不带括号 → 属性（值）
print(obj.method())    # 带括号   → 方法（执行）
```
