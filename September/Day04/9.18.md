## 二、Function Calling 的完整流程（最重要）

```
① 带着 tools 问一次   →  模型说"我要调 X，参数是 Y"
② 你的代码执行 X(Y)   →  拿到结果
③ 结果塞回 messages   →  必须带 tool_call_id
④ 再问一次（不带 tools）→  模型用自然语言回答
```

**核心认知**：
> **模型不执行任何代码，它只负责"决定"；你的代码负责"执行"，再把结果喂回去让它组织成人话。**

### 两种写法对照

| 环节 | 原生 openai SDK | LangChain |
|---|---|---|
| 声明工具 | 手写 JSON Schema 字典 | `@tool` + Pydantic 自动生成 |
| 绑定工具 | `create(tools=tools)` | `llm.bind_tools([...])` |
| 取参数 | `json.loads(tool_calls[0].function.arguments)` | `res.tool_calls[0]["args"]`（已是字典） |
| 执行函数 | 直接调用 `func(**args)` | `tool.invoke(args)` |
| 返回结果 | 手写 `{"role":"tool", ...}` | `ToolMessage(tool_call_id=..., content=...)` |

**底层是同一套流程**，LangChain 只是帮你少写了很多代码。

## 三、今天补的概念

### 1. SDK 是什么

**Software Development Kit**——别人封装好的工具包，让你几行代码就能用复杂服务。

你一行 `client.chat.completions.create(...)`，SDK 在背后帮你做了：拼 URL、加鉴权头、错误处理、超时重试、JSON 解析、包装响应对象。

| 已用过的 SDK | 用途 |
|---|---|
| `openai` | 调大模型 |
| `pymilvus` | 操作 Milvus |
| `FlagEmbedding` | bge-m3 生成向量 |
| `langchain` | 串起整套流程（框架） |
| `python-dotenv` | 读 `.env` |

### 2. 类 / 对象 / 方法 / 属性

| 概念 | 一句话 | 例子 |
|---|---|---|
| **类 Class** | 图纸、模板 | `MilvusClient` |
| **对象/实例** | 照图纸造出来的东西 | `client` |
| **属性** | 对象有什么（数据） | `client.uri`（不带括号） |
| **方法** | 对象能做什么（函数） | `client.search()`（带括号） |
| **实例化** | 照图纸造东西这个动作 | `MilvusClient(uri=...)` |

**三种方法**：
- 实例方法：`client.search()` —— 必须先有对象，第一个参数是 `self`（自动传）
- 类方法：`MilvusClient.create_schema()` —— 直接用类调，用来"造对象"
- 静态方法：无 `self`，也用类直接调

**判断口诀**：`对象.名字` 带 `()` 是方法，不带是属性。

### 3. schema 是什么

**结构设计图 / 表头**——规定有哪些列、每列什么类型，**本身不装数据**。

```sql
CREATE TABLE demo_collection (id BIGINT PRIMARY KEY, ...);   -- 这就是 schema
```

在 Milvus 里：
```python
schema = MilvusClient.create_schema()          # 拿空白设计表
schema.add_field("id", DataType.INT64, is_primary=True)   # 加列
```

### 4. Milvus 完整流程（建索引在第 2 步）

```
① create_schema()              设计结构
② create_collection(index_params)  建集合 + 建索引   ← 索引
   或 create_index()            （也可之后补）
③ insert / upsert              插入数据
④ flush                        落盘
⑤ load_collection              加载（没这步查不到数据）
⑥ search / hybrid_search       检索
```

**索引是"字段级"的**：`vector` 一个索引，`sparse_vector` 一个索引。

## 五、API 调用链怎么读（链式访问）

```python
resp.choices[0].message.tool_calls
```

| 片段 | 含义 |
|---|---|
| `resp` | 整个响应 |
| `.choices` | 候选回复列表（可以同时要多个答案） |
| `[0]` | 取第一个（默认只要一个） |
| `.message` | 模型说的这条消息 |
| `.tool_calls` | 消息里要求调用的工具（列表） |

**诀窍**：看不懂就一层层 `print`，或者 `print(resp.model_dump_json(indent=2))` 看完整结构。
