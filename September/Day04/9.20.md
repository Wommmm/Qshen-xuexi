# 2026-09-20 · Agent 中间件三件套

> 三个中间件，管 Agent 的三件事：**记忆 / 上下文长度 / 出手权限**。
> 共同点：都挂在 Agent 循环的固定钩子上，不写死在业务逻辑里。

---

## 1. 记忆 —— checkpointer + thread_id

| 配置 | 效果 |
|---|---|
| 不传 checkpointer | 每次 invoke 都是新对话，模型"失忆" |
| `InMemorySaver()` | 记得，但进程退出就丢 |
| `SqliteSaver(...)` | 记得，落盘，重启还在 |

```python
from langgraph.checkpoint.memory import InMemorySaver

agent = create_agent(model=llm, tools=[...], checkpointer=InMemorySaver())
config = {"configurable": {"thread_id": "1"}}        # 同一会话用同一个 id
res = agent.invoke({"messages": [{"role": "user", "content": "..."}]}, config)
```

**要点**：`thread_id` 是会话标识，换 id = 开新对话。

## 2. 上下文长度 —— SummarizationMiddleware

到阈值就把旧消息**压成一段摘要**，只留最近几条原文。

```python
SummarizationMiddleware(
    model=summary_llm,
    trigger=("tokens", 4000),      # 或 ("messages", 20)
    keep=("messages", 20),
)
```

**3个坑（必记）**：
1.**为什么今天补显示__interrupt__**：因为我print（res[messages]），transfer_money工具已经被拦截了，所以无法显示，需要print（res）
1. **不传 `trigger` = 完全不生效**（不报错，静默失效）
2. **`fraction` 不能用** —— 它要知道模型的最大窗口，DeepSeek 拿不到，直接报错。用 `tokens` 或 `messages`

**内部怎么做**（面试可讲）：挂在 `before_model`；用 `RemoveMessage` 整体替换历史；摘要以 `HumanMessage` 插回；保证 AI 消息和它的 ToolMessage 成对不被切开；摘要失败只返回错误文本，不抛异常。

## 3. 出手权限 —— HumanInTheLoopMiddleware

敏感操作（转账、下单）不让模型自己决定。

```python
HumanInTheLoopMiddleware(interrupt_on={
    "get_weather": False,      # False → 不拦截
    "transfer_money": True,    # True  → 需要人批准
})
```

**怎么判断中断生效了**：最后一条是带 `tool_calls` 的 `AIMessage`，**且没有 ToolMessage** → 工具没执行，图停住了。

**中断信息在哪**：`res` 顶层，**不在 messages 里**

```python
itr = res["__interrupt__"][0]
itr.value["action_requests"][0]["name"]    # 工具名
itr.value["action_requests"][0]["args"]    # 工具参数（复数 + list）
```

**恢复执行**（三个条件缺一不可：checkpointer + 同一个 thread_id + Command）：

```python
from langgraph.types import Command
agent.invoke(Command(resume={"decisions": [{"type": "approve"}]}), config)
```

三种决策：

```python
{"type": "approve"}                                   # 批准
{"type": "edit", "edited_action": {"name": ..., "args": {...}}}   # 改参数再执行
{"type": "reject", "message": "金额不对"}              # 拒绝
```

## 今天的踩坑（6 条）

| 现象 | 原因 | 解决 |
|---|---|---|
| `Unsupported context size type message` | `keep=("message", 3)` **少个 s** | `("messages", 3)` |
| 看不到 `__interrupt__` | 在 `res["messages"]` 里找，**位置错** | 它在 `res` 顶层 |
| `KeyError: 'therad_id'` | 拼错 | `thread_id` |
| `interrupt.value["action_response"]` | 键名错、且是 list | `action_requests[0]["args"]` |
| 拿到中断却没法恢复 | 缺 checkpointer / thread_id | 补上两个 |
| 注释里写 `"tonkens"` | 注释是错拼源头，照抄必错 | 改 `"tokens"` |
